# DerixTrader

A responsive, single-file front-end hub for five existing bot apps.

## Upload from Android to GitHub
1. Download `index.html` from the provided files.
2. Open https://github.com/mulwamuathime08-hue/derixtrader
3. Tap **Add file** → **Upload files**.
4. Select `index.html` and upload it to the repository root.
5. Commit the changes to `main`.
6. Open **Settings** → **Pages**. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.

The public market widget requests Deriv's public R_10 tick stream. It does not authenticate or place trades. Keep API tokens and secrets out of this repository. Authenticated trading requires a secure backend/integration and separate verification.
